## [1.0.0] - 2026-11-06

Первый релиз форка. gramvanity вырос из
[necrovolt/seedvanity](https://github.com/necrovolt/seedvanity) и сохраняет ту же
идею: поиск ведётся по настоящим сид-фразам, поэтому найденный адрес — тот,
который кошелёк показывает при импорте. Глобальные изменения относительно
оригинального проекта:

### Движок поиска

- Монолитный `opencl/seedvanity.c` переписан в модульное дерево `opencl/src/`.
- Вывод публичного ключа Ed25519 выполняется на GPU (`opencl/ed25519_gpu.cl`) —
  снимается узкое место на CPU для дискретных GPU; для независимой CPU-проверки
  каждого хита вендорится ed25519-donna.

### Процесс поиска

- Один запуск ищет несколько адресов сразу, у каждого свои паттерны, лимиты и вывод.
- Все файлы прогона лежат в одной job-папке (хиты, стоп-отчёт, чекпоинт).
- Формат чекпоинта хранит эти цели; чекпоинты старых версий продолжают загружаться.
- Hit-файлы перечисляют все совпавшие цели (`hit-A+B-<index>.txt`).

### Кошельки

- Поддержка Telegram Wallet (WalletTg): специальные 24-словные фразы и однократная
  активация через `w5addr activate`; `--mode tg-wallet` — режим по умолчанию.
- Верификатор переписан с Node.js на Go (`verify-go/`): независимый пересчёт хитов
  на tonutils-go плюс команда активации.

### Платформы и сборка

- Сборка macOS/Metal удалена; поддерживаются Linux и Windows через OpenCL.
- Единый скрипт сборки Windows (`build-windows.sh`, MSYS2 UCRT64).

### Качество и документация

- GPU-набор `opencl/tests/test_det.sh` (20 сценариев, 113 проверок) и `--selftest-det`
  (~50 CPU-ассертов).
- CI на GitHub Actions (Linux + Windows) и релизы по тегу с готовыми архивами.
- Двуязычная документация (английский/русский) и локализация `--lang en|ru`.
